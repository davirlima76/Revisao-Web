## 🎯 Sobre o projeto

O **Revisão 3º Ano A** é uma plataforma web desenvolvida para auxiliar estudantes do **3º ano do Ensino Médio** na preparação para as avaliações.

A proposta é reunir em um único ambiente os principais conteúdos das disciplinas, materiais de revisão e questões para prática, permitindo que o aluno estude de forma mais organizada e acompanhe seu próprio desempenho.

## 🎮 Como utilizar

### 📖 Revisar

Acesse **Matérias** e escolha a disciplina que deseja estudar.

Você poderá acessar os conteúdos organizados por tópicos e avançar pela revisão.

### 📝 Praticar

Acesse **Questões** para responder perguntas relacionadas aos conteúdos estudados.

Após selecionar uma alternativa, o sistema informa se a resposta está correta e apresenta uma explicação.

### 📊 Acompanhar

Na página **Desempenho**, é possível acompanhar:

```text
Testes realizados
       ↓
Questões respondidas
       ↓
Média de acertos
       ↓
Pontuação
       ↓
Histórico
```

Os resultados são armazenados no navegador utilizando **LocalStorage**.

## 🎓 Objetivo

O principal objetivo do projeto é transformar a revisão escolar em uma experiência mais **organizada, interativa e prática**.

A ideia é que o estudante não apenas leia o conteúdo, mas também:

> **Estude → Pratique → Receba feedback → Acompanhe seu desempenho → Melhore**
